### 👨‍💻 About Me

- 🎓 **Student:** Computer Science / IT student dedicated to turning concepts into functional software.
- 💻 **Core Focus:** Building responsive web apps, native Android applications, and interactive games.
- 🚀 **Latest Project:** [TASKNOVA](https://github.com/nikesh07662/TASKNOVA) — An AI-powered academic workflow automation platform that connects Google Classroom, Microsoft Teams, Google Drive, OneDrive, ChatGPT and Gemini.
- 🎮 **Game Dev:** [SkyBoundRush](https://github.com/nikesh07662/SkyBoundRush) — A 2D high-altitude flight arcade game built with Unity 6 LTS and C#.

- 🌱 **Currently Exploring:** Android Clean Architecture (Jetpack Compose), AI agents/LLM integrations, and game development.
- 🎯 **Goals:** Collaborate on open-source projects and build a portfolio of impactful applications.
